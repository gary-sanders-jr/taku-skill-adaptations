# Performance Profile Result Evidence Ledger

Use only after profiling has already occurred and the user supplies sanitized results. Record workload, environment, sampling method, duration, hot paths, resource signals, comparison baseline, attribution limits, missing intervals, and unknowns. Label each conclusion `supported`, `contradicted`, or `insufficient`; do not turn correlation into causation.

Return a private ledger and proposed human-run checks marked `NOT RUN`. Do not access profilers, systems, files, repositories, networks, accounts, dashboards, or telemetry; run commands or benchmarks; change code or capacity; approve a fix; send; or publish.
