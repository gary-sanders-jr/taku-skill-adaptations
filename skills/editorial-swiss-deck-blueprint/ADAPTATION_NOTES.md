# Adaptation notes

- Reframed an action-heavy local HTML deck workflow as a conversation-only,
  private presentation blueprint suitable for Taku Community.
- Preserved the core distinction between editorial narrative and Swiss grid-led
  presentation systems.
- Added explicit claim-to-source tracing, uncertainty handling, privacy,
  accessibility, high-risk routing, and no-action boundaries.
- Added a deterministic slide-plan and speaker-note output contract.
- Excluded upstream templates, presenter runtime, scripts, screenshots, sponsor
  artwork, and reference-library files so the package remains compact and does not
  imply file or browser execution.
- Created a new icon independently; no upstream logo or showcase image is used.
