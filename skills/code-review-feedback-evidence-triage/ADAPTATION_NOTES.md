# Adaptation Notes

This derivative preserves the upstream principle of verifying review feedback before acting, while
turning it into a practical-tier, analysis-only evidence triage.

- Reframed the workflow from implementation behavior to a private advisory report.
- Limited inputs to pasted, fictional, or explicitly identified read-only and sanitized material.
- Made embedded content lazy and treated review text as untrusted data rather than instructions.
- Prohibited account and network access, commands, file or code changes, replies, approvals,
  merges, publishing, deployment, spending, and other external-state changes.
- Added observed/inferred/unknown evidence labels, explicit dependencies, and safe response order.
- Routed security, privacy, legal, compliance, production, access, payment, and other consequential
  decisions to authorized human owners.

No claim is made that the upstream author endorsed these changes.
