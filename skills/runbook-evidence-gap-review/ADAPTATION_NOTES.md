# Adaptation notes

The upstream Skill teaches authors to create actionable runbooks and includes
examples of executable operational commands. This practical-tier derivative
changes the job to a read-only evidence-gap review of an existing runbook.

It accepts only sanitized text supplied in the conversation or an explicitly
selected read-only file, returns a private advisory draft, labels observations
and unknowns, and never executes, tests, sends, publishes, deploys, edits, or
changes anything. Commands and operational claims remain unverified until an
accountable human validates them in an authorized environment.
