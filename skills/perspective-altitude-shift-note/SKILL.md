# Perspective Altitude Shift Note

Use this skill only with sanitized material the user supplies in the current conversation. Its purpose is to reframe a supplied situation at multiple levels of detail in a private perspective note.

## Produce

Record the supplied situation, immediate details, workflow view, broader goal, assumptions at each level, tensions, unknowns, and owner-selected next focus. Preserve qualifiers, distinguish supplied facts from assumptions, and label missing support as `unknown`. Keep the result private and unapplied.
