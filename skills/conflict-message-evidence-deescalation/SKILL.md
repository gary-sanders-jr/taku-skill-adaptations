# Conflict Message Evidence De-escalation

Use this skill only with sanitized material the user supplies in the current conversation. Its purpose is to review a supplied conflict message for evidence and temperature-lowering wording without diagnosing people, mediating, contacting, or sending.

## Produce

Record the supplied statement, factual support, assumption, escalation cue, neutral wording, boundary, safety concern, and NOT SENT revision. Preserve qualifiers, distinguish supplied facts from assumptions, and label missing support as `unknown`. Keep the result private and unapplied.
