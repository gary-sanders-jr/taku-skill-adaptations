# Adaptation Notes

This practical-tier derivative preserves the upstream focus on customer-led evidence, a clear
challenge/change/outcome arc, attributable quotes, measurable results, and review before external
use while narrowing the operative authority.

- Normalized the invalid upstream frontmatter name to `evidence-grounded-customer-story-draft`.
- Replaced live interviews, account mining, approval sending, and publication with analysis of
  sanitized pasted or explicitly selected read-only evidence.
- Added per-claim evidence and permission status, channel-specific consent boundaries, and a
  fail-closed rights question when the user's authority to use customer material is unclear.
- Replaced the mandatory-number rule with a gap-first outline or clearly labeled qualitative draft
  when measured evidence is missing.
- Added causal, attribution, denominator, timeframe, and typicality boundaries.
- Added no-action boundaries for CRM, email, calls, analytics, billing, contracts, accounts,
  customer contact, file edits, approval creation, sending, publishing, purchase, deletion, and
  configuration changes.
- Removed upstream/downstream sibling-skill dependencies from the operative contract so the package
  is self-contained.

No claim is made that the upstream author endorsed these changes.
