# Clean-room implementation notes

- No upstream file was used as drafting input.
- The Skill has a new product boundary: a pre-implementation decision contract,
  not persistent agent configuration or coding instructions.
- It separates blocking, boundable, and deferrable uncertainty.
- It compares viable approaches, freezes the minimum change, defines observable
  success evidence, and states stop conditions.
- It is conversation-only and performs no repository, file, command, account,
  network, code, version-control, review, or deployment action.
- The dedicated icon is independently generated and uses no upstream branding.
