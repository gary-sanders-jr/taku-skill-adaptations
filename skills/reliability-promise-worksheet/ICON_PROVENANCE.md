# Icon provenance

The icon was created locally as deterministic SVG geometry for this adapted
Skill and converted to PNG with macOS `sips`. It contains no upstream brand,
text, letters, numbers, checkmark, badge, shield, lock, or watermark.

Visual metaphor: three measured reliability lanes crossing an amber allowance
window, with a single observation marker. The composition represents evidence,
thresholds, and a bounded error budget without implying approval or deployment.
