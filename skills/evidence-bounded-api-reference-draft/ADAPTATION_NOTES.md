# Adaptation Notes

This practical-tier derivative preserves the upstream emphasis on searchable reference structure,
complete parameter and error documentation, operational contracts, examples, and source truth
while narrowing the operative authority.

- Reframed automatic generation and live testing as a private evidence-bounded documentation draft.
- Limited inputs to sanitized pasted material and explicitly selected read-only files.
- Added per-claim provenance, contradiction handling, and an explicit unknowns ledger.
- Required fictional values and verification labels for examples instead of live credentials or
  unproved runnable claims.
- Added no-action boundaries for accounts, endpoints, repositories, secrets, execution, source
  edits, configuration, migrations, deployment, publishing, sending, purchase, and deletion.
- Added accountable review routing for security, privacy, regulated-data, payment, contractual,
  destructive, and production-sensitive claims without implying certification.
- Removed sibling-skill dependencies from the operative contract so the package is self-contained.

No claim is made that the upstream author endorsed these changes.
