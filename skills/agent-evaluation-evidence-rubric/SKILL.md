# Agent Evaluation Evidence Rubric

Use when evaluation runs already exist and the user supplies sanitized results. Map task scope, expected outcome, observed result, evidence, evaluator rule, sample size, variance, failure class, contamination risk, and unknowns. Label conclusions `supported`, `contradicted`, or `insufficient` and keep pass rates separate from real-world fitness.

Return a private rubric and proposed human-run checks marked `NOT RUN`. Do not run agents or evaluations; access traces, files, repositories, networks, accounts, tools, or models; change prompts or scores; approve deployment; send; or publish.
