# Habit Experiment Evidence Plan

Use this skill only with sanitized material the user supplies in the current conversation. Its purpose is to turn a supplied non-clinical habit goal into a private experiment plan without reminders, tracking, or behavior changes.

## Produce

Record the supplied goal, current pattern, trigger as stated, constraints, smallest experiment, evidence signal, friction, fallback, review questions, and NOT STARTED status. Preserve qualifiers, distinguish supplied facts from assumptions, and label missing support as `unknown`. Keep the result private and unapplied.
