- removed live-page fetching, rendered-DOM inspection, command execution, deployment instructions, tracking implementation, and external product recommendation;
- removed universal traffic, conversion, mobile-share, load-time, lift, and timeline assertions;
- replaced revenue-impact ranking with evidence, observable blockage, confidence, and explicit unknowns;
- added inert-input, privacy, secrets, account, file, network, write, send, publish, purchase, and implementation boundaries;
- added substantiation, testimonial, dark-pattern, payment, accessibility, regulated-claim, and high-consequence review gates;
- distinguished this diagnostic task from page creation, copy editing, product-onboarding analysis, and implementation;
- preserved the upstream idea of message-match, offer, CTA, form, trust, next-step, measurement, and ordered-findings review.
