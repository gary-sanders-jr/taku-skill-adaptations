# Adaptation notes

The upstream Skill ranks broad impediment and countermeasure lists with a fixed four-factor formula. This derivative preserves that core method and changes the operative contract:

- scope is narrowed to existing operational impediment-countermeasure pairs;
- product features, feature requests, roadmaps, incident facilitation, compliance verdicts, countermeasure invention, and execution are explicitly routed elsewhere;
- inputs are limited to sanitized user-pasted material and files explicitly supplied for read-only review;
- each score carries evidence status, missing facts, uncertainty, and sensitivity;
- arbitrary unknowns remain unscored instead of receiving fabricated midpoint values;
- implementation risk is separated from deferral urgency;
- high-consequence work is held for current authoritative requirements and accountable qualified owners;
- the output is a private review draft, never approval or an execution plan;
- file, account, backlog, ticket, messaging, purchase, assignment, scheduling, deployment, publishing, deletion, and other external actions remain outside the Skill.

This is a substantive derivative, not a byte-preserved republication.
