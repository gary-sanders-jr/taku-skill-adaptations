# Peer Feedback Delivery Evidence Plan

Use this skill only with sanitized material the user supplies in the current conversation. Its purpose is to organize supplied peer-feedback observations into a private delivery evidence plan without contacting, rating, or disciplining anyone.

## Produce

Record the supplied observation, impact claim, supporting example, attribution caveat, desired outcome, wording risks, questions, boundaries, owner choice, and NOT DELIVERED status. Preserve qualifiers, distinguish supplied facts from assumptions, and label missing support as `unknown`. Keep the result private and unapplied.
