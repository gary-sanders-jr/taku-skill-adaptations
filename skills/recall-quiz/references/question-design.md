# Question Design

`SKILL.md` is authoritative.

Use exactly one defensible answer and parallel options. Build distractors only from misconceptions, reversals, adjacent concepts, or sequence errors explicitly taught in the immediately preceding answer. Never import a fact from model memory to make a distractor plausible.

Safe low-risk examples include distinguishing a programming interface from its implementation, choosing the correct step in a hobby process, or identifying the role of retrieval in a supplied RAG explanation. Do not use legal, tax, investment, medical, employment, safety, or other consequential examples.

Reject trick questions, double negatives, “all/none of the above,” joke answers, two defensible answers, hidden outside knowledge, and questions about personal details. If there is insufficient grounded material, skip or say that a fair question cannot yet be made.
