# Learning Science

`SKILL.md` is authoritative.

Retrieval practice is a widely studied learning technique: attempting to recall recently learned material and then receiving corrective feedback can support retention. The effect varies with the learner, material, question quality, spacing, prior knowledge, and context.

Do not present precise study statistics, dates, regulatory claims, universal forgetting schedules, or causal promises unless the user supplies a current authoritative source for review. Do not claim that AI use necessarily causes cognitive decline or that this Skill prevents deskilling. Describe the quiz as an optional, low-friction practice aid, not a validated assessment or guaranteed intervention.
