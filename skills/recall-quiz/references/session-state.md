# Session State

`SKILL.md` is authoritative.

Track only a minimal working-memory note inside the current conversation: topic, hit/miss/skip, and approximate difficulty. Do not write files, use databases, create flashcards, set reminders, access a learning platform, or claim memory across sessions.

A miss may return later in reworded form only if the user remains opted in. Repeated skips are a soft opt-out. Keep no visible score unless requested, never frame a low score as failure, and make no claim about mastery, grades, or certification readiness.
